# Zepto SQL Data Analysis Project

## Project Overview
This project focuses on analyzing Zepto product data using SQL and PostgreSQL. The objective is to extract meaningful business insights related to product pricing, discounts, inventory, and category-wise revenue.

## Tools & Technologies
- PostgreSQL
- pgAdmin 4
- SQL
- Git & GitHub

## Business Questions Solved

1. Find the top 10 best-value products based on the discount percentage.
2. Identify products with high MRP but out of stock.
3. Calculate estimated revenue for each category.
4. Find products where MRP is greater than ₹500 and discount is less than 10%.
5. Identify the top 5 categories offering the highest average discount percentage.
6. Calculate price per gram for products above 100g and sort by best value.
7. Group products into categories like Low, Medium, and Bulk.
